# Technical tools

Offline evidence builders, financial report renderers, lifecycle utilities, package smoke checks and NEAR testnet helpers. Research runners require explicit inputs and may use funded models only when configured and approved. Private output archives are not bundled. Browser SDK rebuild tooling is maintained in Boyun-interface.

Optional presentation export helpers are external dependencies. Set `BOYUN_PRESENTON_SCRIPTS` to an independently installed Presenton scripts directory before using those exporters. No third-party skill is bundled.
